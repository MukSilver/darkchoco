# 포럼 조사 결과를 수집 DB 에 올리는 서식
#
# 쓰는 법
#     이 파일을 복사해 값을 채운 뒤 아래를 돌린다. 미리보기가 기본이다.
#
#     python tools/notion_row.py 수집 조사.txt --set "수집자=<내 이름>"
#     python tools/notion_row.py 수집 조사.txt --set "수집자=<내 이름>" --commit
#
# 왜 서식이 있나
#     팀원마다 쓰는 AI 가 다르다. 「알아서 노션에 올려 줘」 하면 AI 마다 칸 이름과
#     선택지를 제 나름대로 읽어 오류와 누락이 난다. **이 서식을 채우게 하면 AI 가
#     달라도 결과가 같다.**
#
# 규칙
#     * `#` 로 시작하는 줄은 무시한다. 설명이다
#     * 한 줄에 `칸 이름: 값` 하나다. 칸 이름을 바꾸지 마라
#     * 모르는 칸은 **값을 비우고 그대로 둔다.** 지어내지 않는다
#     * 여러 값을 넣는 칸은 쉼표로 나눈다
#     * 선택지가 정해진 칸은 아래 적힌 것 중에서 고른다. 없는 값은 노션이 거부한다
#     * 개인정보 값을 여기 적지 않는다. 나가는 것은 칸 이름과 패턴과 건수뿐이다
#
# 겹침
#     도구가 올리기 전에 이미 있는 줄인지 본다. 열쇠는 `UID` → `원문 URL` →
#     `제목|게시 플랫폼` 차례다. **`원문 URL` 을 꼭 채워라.** 비면 제목과 플랫폼으로
#     만 보는데, 기계가 올린 같은 글과 표기가 어긋나 중복이 들어온다.
