# 폴더를 어디에 두나

    적은 날    2026-09-09
    누구에게    검증 도구를 자기 PC 에서 돌리는 팀원
    왜        사람마다 폴더 자리와 이름이 달라서, 도구가 어디를 보는지 알아야 한다

---

## 한 줄

**재료는 VM 공유폴더로 들어오고, 결과는 프젝의 `07_케이스` 에 남는다.**

---

# 1. 두 자리를 가른다

| | 무엇이 있나 | 지우나 |
|---|---|---|
| **공유폴더** | VM 에서 압축을 푼 재료 | **케이스가 끝나면 비운다** |
| `07_케이스/` | 분석 결과 md | 남긴다 |

공유폴더는 **통로지 창고가 아니다.** VM 안에서만 다뤄야 하는 유출물이
호스트로 넘어오는 자리라, 오래 두면 그만큼 위험이 는다.

`07_케이스` 에 남는 것은 값이 아니라 **필드명·패턴·건수**다. 그것만 기사로 나간다.

---

# 2. 공유폴더 이름은 사람마다 다르다

VirtualBox 설정에서 정하는 것이라 `VM공유폴더` 가 아닐 수 있다.
도구는 아래 순서로 찾는다.

    1. DARKCHOCO_QUEUE 환경변수     있으면 무조건 이것
    2. <프젝>/VM공유폴더            없으면 이 자리

**프젝 폴더도 사람마다 다르다.** `DARKCHOCO_PROJ` 로 정한다. 안 정하면
`~/Documents/Q.E.D/화햇/화햇강의자료/프젝` 을 본다.

## 환경변수를 정하는 법

**윈도우** — PowerShell 에서 한 번만 하면 계속 남는다.

```
setx DARKCHOCO_PROJ  "D:\내작업\프젝"
setx DARKCHOCO_QUEUE "D:\내작업\프젝\share"
```

`setx` 는 **새 창부터** 적용된다. 지금 열린 창에는 안 들어온다.

**맥·리눅스** — `~/.zshrc` 나 `~/.bashrc` 에 적는다.

```
export DARKCHOCO_PROJ=~/work/프젝
export DARKCHOCO_QUEUE=~/work/프젝/share
```

## 잘 잡혔는지 보는 법

`0 처음설정.bat` 을 누르면 「검증 큐 폴더」 줄에 자리가 나온다.
없다고 나오면 위 환경변수를 정하거나 그 자리에 폴더를 만든다.

---

# 3. 케이스 하나가 폴더 하나다

    <공유폴더>/
        dlenc/                    ← 케이스 이름. 짧게 짓는다
            상태.json             **이 파일이 있어야 큐에 잡힌다.** {} 만 있어도 된다
            자료/                 **압축을 푼 재료를 여기 둔다**
                Users/
                C/
            ②본문.md              게시글 원문. 사람이 옮겨 둔다
            ②샘플.txt             샘플 줄만. 사람이 옮겨 둔다
            ③_재료판정.txt         도구가 쓴다
            ③재료.md              도구가 조립한다. 이것을 스킬에 넣는다

## 왜 `자료/` 밑에 두나

케이스 폴더 바로 아래에 풀면 **도구가 낸 산출물이 재료 목록에 섞인다.**
`inspect.py` 가 `③_재료판정.txt` 를 재료로 세어 버린다.

## `상태.json` 을 만드는 법

빈 객체 하나면 된다. 도구가 나머지를 채운다.

```
{}
```

메모장으로 만들 때는 **저장할 때 인코딩을 UTF-8 로** 고른다.

# 4. 도구를 부르는 법

## 제어판에서

「큐와 케이스」 메뉴로 들어간다. 큐 폴더 자리가 화면 위에 나온다.

    큐 상태 보기                     아무것도 안 돌린다. 어디까지 됐는지만 본다
    큐 한 바퀴 돌리기                기계로 되는 부분을 돌린다
    브리핑 만들기                    07_케이스 에 md 를 낸다
    수집 표에서 큐 채우기             수집 DB 에서 케이스 폴더를 만든다

## 직접 부를 때

경로를 인자로 준다. 도구에 자리가 박혀 있지 않다.

```
python tools/run_queue.py <공유폴더>              상태만 본다
python tools/run_queue.py <공유폴더> --go         돌린다
python tools/run_queue.py <공유폴더> --go --case dlenc
```

---

# 5. 도구가 멈추는 자리 넷

**멈춤은 실패가 아니다.** 사람이 볼 자리라는 뜻이다.

| 멈추는 자리 | 왜 | 무엇을 하나 |
|---|---|---|
| 압축이 안 풀렸다 | 도구가 압축을 열지 않는다 | VM 에서 풀어 `자료/` 에 둔다 |
| 같은 케이스가 이미 있다 | 새 조사를 시작하지 않는다 | 기존 줄에 이어 붙인다 |
| 이름을 속인 파일이 있다 | 어느 도구에도 안 태운다 | 사람이 먼저 본다 |
| 재료가 크다 | 착수 전에 고른다 | 무엇을 볼지 정한다 |

---

# 6. 끝나면

1. `07_케이스/<케이스>/` 로 결과 md 를 옮긴다
2. **공유폴더의 케이스 폴더를 지운다**
3. VM 안의 원본도 지운다

재배포하지 않는다. 원본을 팀 밖으로 내보내지 않는다.
