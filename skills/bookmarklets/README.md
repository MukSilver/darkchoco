# 북마클릿

브라우저 주소 칸에 넣어 쓰는 수집 도구다. 사람이 연 페이지에서 누른다.
스킬이 부르지 않는다. `skills/darkweb-verify-ko/tools/` 의 파이썬과 별개다.

## 무엇이 있나
*중요: 통합은 글자수가 많아서 북마크 자체가 안 만들어질 수 있음, 포럼 조사 하나씩 쓰세요*
**통합 킷 하나면 된다.** 다섯을 담고 있고 페이지를 보고 맞는 것을 켜 준다.

| 파일 | 크기 | 무엇 |
|---|---|---|
| `darkchoco_kit.bookmarklet.txt` | 57,055자 | **다섯을 하나로.** 판정하고 고르게 한다 |

따로 쓰고 싶으면 다섯이 그대로 있다.

| 파일 | 크기 | 어디에 | 무엇 |
|---|---|---|---|
| `forum_kit.bookmarklet.txt` | 28,661자 | MyBB·XenForo 포럼 | 게시판 지도, 글 목록, 본문, 구조 진단 |
| `qilin_kit.bookmarklet.txt` | 11,097자 | 킬린 랜섬웨어 유출 사이트 | 피해자 목록, 증거 사진 수, 파일 목록 |
| `index_kit.bookmarklet.txt` | 8,604자 | 노출된 디렉터리 인덱스 | 폴더만 걸어다니며 경로 목록 |
| `photo_kit.bookmarklet.txt` | 7,374자 | 피해자 글의 증거 사진 | 개수를 정해 받는다. **유일하게 파일을 받는다** |
| `probe_generic.bookmarklet.txt` | 4,111자 | 구조를 모르는 사이트 | DOM 진단. 무엇을 긁을지 정할 때 |

## 파일이 열여섯인데 쓰는 것은 하나다

역할이 넷으로 나뉜다.

| 역할 | 파일 | 언제 |
|---|---|---|
| **북마크에 넣는 것** | `darkchoco_kit.bookmarklet.txt` | 평소 |
| 폴백 | 나머지 `.txt` 다섯 | 통합 킷이 주소 칸에서 잘릴 때 |
| 소스 | `.js` 여섯 | 고칠 때 |
| 빌더 | `build_kit.py` · `build_bookmarklet.py` | 고친 뒤 |

**소스 다섯은 복사본이 아니라 재료다.** 통합 킷이 그 다섯에서 만들어진다.

    forum_kit.js ┐
    qilin_kit.js │
    index_kit.js ├─ build_kit.py ─→ darkchoco_kit.js ─→ build_bookmarklet.py ─→ .txt
    photo_kit.js │
    probe_generic.js ┘   kit_shell.js ┘

지우면 통합 킷을 다시 못 만든다. `forum_kit` 이 소스를 잃어 압축본에서 복구한 적이 있다.

**`darkchoco_kit.js` 는 손으로 고치지 마라.** `build_kit.py` 가 만든 것이라 다시 빌드하면 덮어쓴다.

## 통합 킷

누르면 오른쪽 위에 작은 판이 뜬다. **판정된 것이 초록으로 켜져 있다.**

    포럼 · 킬린 · 디렉터리 · 증거 사진 · 구조 진단

판정이 틀렸으면 다른 것을 누르면 된다. 고른 것이 자기 상자를 만들고 작은 판은 사라진다.
**한 번에 하나만 뜬다.**

모듈 하나가 멈춰도 나머지는 멀쩡하다. 멈추면 무엇이 멈췄는지 적어 보여준다.

각 모듈은 따로 쓰던 킷의 본문 그대로다. **동작이 바뀌지 않았다.**

## 처음 쓸 때

`디렉터리` 는 **초동분석** 부터 누른다. 요청을 50회로 묶어 3분 안에 끝난다.
너비 우선이라 위쪽 층이 통째로 남으므로 그것만으로 윤곽이 나온다.
등급이 높은 가지를 찾으면 그 주소를 열고 다시 눌러 깊이 들어간다.

    초동분석 3분   요청 50회로 묶어 빠르게
    전체 수집      깊이와 요청상한을 직접 정한다
    이 폴더만      네트워크를 안 쓴다. 지금 화면만 읽는다

## 최소화

다 화면 오른쪽 아래로 접힌다. `최소화` 를 누르면 상자가 줄고 **상태줄과 중단 버튼만 남는다.**
걸어다니는 중에 아래 페이지를 보면서 진행 상황을 확인할 때 쓴다. `펼치기` 로 되돌린다.

## 어떻게 쓰나

`.bookmarklet.txt` 안의 한 줄을 북마크 주소로 넣는다. 대상 페이지에서 그 북마크를 누른다.

`.js` 를 고쳤으면 반드시 다시 만든다.

    python bookmarklets/build_bookmarklet.py

`node --check` 를 통과해야만 txt 를 쓴다. 실패하면 옛 txt 를 그대로 둔다.

다섯 중 하나를 고쳤으면 통합 킷도 다시 만든다.

    python bookmarklets/build_kit.py
    python bookmarklets/build_bookmarklet.py

## 최소화 도구

`terser` 가 있으면 변수명까지 줄인다. 없으면 줄만 합친다. **없다고 멈추지 않는다.**

    forum_kit   41,035  ->  28,661
    통합 킷      92,731  ->  57,055

빌드할 때만 쓴다. 검증 파이프라인 안에서 돌지 않고 컨테이너에도 안 들어간다.

**최소화하면 사람이 못 읽는다.** 그래서 소스를 레포에 둔다.
`forum_kit` 이 한동안 소스를 잃었던 것이 그 규칙이 없어서였다.
2026-08-24 에 압축본 안에서 찾아 복구했다.

## 크기

60,000자를 넘으면 주소 칸에서 잘릴 수 있다고 빌더가 알린다.
**그 숫자는 보수적으로 잡은 것이고 실측한 값이 아니다.**

통합 킷이 57,055자라 지금은 경고가 안 뜬다. **그래도 실측은 아니다.**
넣어 보고 잘리면 다섯을 따로 쓰면 된다.

2026-08-25 에 겹친 껍데기를 뜯어 61,393 에서 57,055자가 됐다.

## 공통 껍데기

`kit_shell.js` 에 상자·상태줄·출력칸·버튼 공장·최소화가 들어 있다.
`qilin`·`index`·`photo` 셋이 이것을 쓴다. 셋의 UI 가 63줄 중 53줄이 같았다.

**`forum_kit` 과 `probe_generic` 은 안 쓴다.** 껍데기 모양이 다르다.
`probe_generic` 은 버튼이 하나뿐이고 `forum_kit` 은 최소화 블록이 다르다.
억지로 맞추면 둘 다 고쳐야 해서 그대로 뒀다.

`BUSY` 와 `ABORT` 는 모듈이 들고 있다. 껍데기는 넘겨받은 함수로만 만진다.
모듈 본문의 수집 반복문이 `ABORT` 를 직접 읽기 때문이다.

    /* @shell */
    const S = mkShell({ busy: () => BUSY, setBusy: v => { BUSY = v; },
                        setAbort: v => { ABORT = v; } });

`/* @shell */` 표시를 빌더가 다르게 다룬다.

| 빌더 | 무엇 |
|---|---|
| `build_bookmarklet.py` | 표시 자리에 껍데기를 넣는다. 따로 쓰는 킷은 혼자 돌아야 한다 |
| `build_kit.py` | 표시를 지우고 껍데기를 맨 앞에 **한 번만** 둔다 |

**따로 쓰는 셋은 조금 커졌다.** 껍데기가 함수로 감싸이면서 285자 안팎이 붙는다.
한 번만 쓰는 자리에서는 안에 그대로 적는 편이 짧다. 대신 고칠 자리가 하나가 됐다.

`kit_shell.js` 는 북마클릿으로 만들지 않는다. 혼자서는 안 돈다.

## 고칠 때 지킬 것

- **`//` 주석을 쓰지 마라.** 한 줄로 합치면 뒤가 통째로 주석이 된다. `/* */` 를 쓴다.
  줄 맨 앞이든 줄 끝이든 빌더가 막는다
- **요청 간격을 줄이지 마라.** 계정과 회선을 셋이 공유한다.
  포럼은 입력칸에서 바꿀 수 있지만 **하한 2초** 아래로는 안 내려간다
- 403, 429, 503, Cloudflare 문구면 즉시 중단한다
- 파일을 받는 것은 `photo_kit` 하나뿐이다. 다른 kit 에 받는 기능을 넣지 마라
- 받는 도구는 개수 상한을 반드시 둔다. 기본을 낮게 잡는다
- **`.txt` 와 `darkchoco_kit.js` 를 손으로 고치지 마라.** 둘 다 만들어지는 파일이다.
  고칠 자리는 킷 다섯과 `kit_shell.js` 여섯뿐이다
