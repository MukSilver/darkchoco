# ② 게시글 확인

사람이 한다. 프롬프트 없음.

재료

| 재료 | 성격 |
|---|---|
| 게시글 본문, 샘플 | 판매자가 보여주기로 한 것 |
| **파일 트리** | 확보한 유출물의 구조 전체 |

| 무엇 | 계상 |
|---|---|
| 판매자가 게시글에 올린 트리 캡처 | 게시글 내용이다. 독립 근거로 계상하지 않는다 |
| 우리가 확보한 실물 트리 | 게시글 밖 사실이다. 계상한다 |

**하면 안 되는 것.** 트리에서 토큰이나 자격증명이 보여도 살아있는지
확인하려고 요청을 보내지 않는다. 남의 자격증명을 실제로 쓰는 행위다.
존재와 패턴까지만 기록한다.

---

## 파일로 받았으면 종류부터 본다

**확장자를 믿지 않는다.** 이름과 앞바이트가 어긋난 파일이 섞여 온다.
폴더를 통째로 넘겨 판정한다.

    python tools/inspect.py <케이스폴더>
    python tools/inspect.py <케이스폴더> --out <결과폴더>

앞바이트로 진짜 종류를 정하고, 이름에 숨은 방향 제어 문자를 따로 낸다.
`00_요약.md` 의 **이름을 속인 파일** 절에 어긋난 것이 모인다.
**그 파일은 아래 흐름에 넣지 않는다.**

압축은 도구가 열지 않는다. `inspect.py` 는 이미 풀린 폴더만 본다.
**푸는 것은 격리 환경에서 하고, 풀기 전에 목록을 먼저 본다.**

종류가 정해지면 텍스트로 확인된 것만 다음으로 넘긴다.

| 판정된 종류 | 다음 도구 |
|---|---|
| SQL 덤프 | `tools/db_tree.py` |
| 파일 경로 목록, 압축 목록 | `tools/tree_scan.py` |
| CSV, 텍스트 샘플 | 도구 없이 ④ 로 |
