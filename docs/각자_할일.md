작성일 2026-08-26 · 다크초코

공용 부품 4개가 `packages/` 에 준비되었습니다. 각 앱이 그것을 쓰도록 바꾸는
작업입니다. 아래 그대로 따라 하면 됩니다.

## 0. 시작 전 · 모두 공통

```bash
git pull
git switch -c feat/내앱이름-공용부품
```

바꿀 파일 맨 위에 이 두 줄을 넣습니다. 어느 앱이든 똑같습니다.

```python
import sys
from pathlib import Path
sys.path.insert(0, str(Path(__file__).resolve().parents[2] / "packages"))
```

`parents[2]` 는 `apps/앱이름/파일.py` 기준입니다.
`skills/` 안의 파일은 깊이가 다르니 `parents[3]` 이 될 수 있습니다.
경로가 맞는지는 실행해 보면 바로 압니다.

## 1. 텔레그램 접속 바꾸기 — 이수빈 · 성민서

`check_login.py` · `list_channels.py` 두 파일에서 아래 부분을 찾습니다.

**지우는 것**

```python
from telethon import TelegramClient

api_id = int(os.environ["TELEGRAM_API_ID"])
api_hash = os.environ["TELEGRAM_API_HASH"]
client = TelegramClient(str(SESSION_PATH), api_id, api_hash)
```

**넣는 것**

```python
from dc_telegram import make_client

client = make_client(SESSION_PATH)
```

`import os` 가 다른 데서 안 쓰이면 같이 지웁니다.

실제 예시는 `apps/tg-korea-alert/check_login.py` 를 보면 됩니다.
이미 바꿔 두었습니다.

## 2. 텔레그램 수집 바꾸기 — 이수빈 · 성민서

`collect_messages.py` 는 파일이 크니 **함수 본체를 통째로 대체**합니다.

**이수빈 · tg-notion-report**

```python
from dc_telegram import collect_messages

payload = await collect_messages(
    channel,
    output,
    limit=limit,
    incremental=incremental,   # 기존 증분 수집 그대로
    with_meta=True,            # 발신자·포워드·리액션 그대로
)
```

**성민서 · tg-korea-alert**

```python
from dc_telegram import collect_messages, parse_day

payload = await collect_messages(
    channel,
    output,
    limit=limit,
    from_day=from_date,        # 기존 날짜 범위 그대로
    to_day=to_date,
    timezone_name="Asia/Seoul",
    with_meta=False,
)
```

`parse_args()` 와 명령행 옵션은 그대로 둡니다. 값만 넘겨주면 됩니다.

파일 안의 `parse_channel` · `isoformat` · `sender_metadata` 같은 함수들은
전부 `dc_telegram` 안에 들어가 있으니 지웁니다.

## 3. 노션 바꾸기 — 이수빈 · 안유빈 · 최현서

**안유빈 · dls-observatory**

```bash
git rm apps/dls-observatory/notion.py
```

이 파일이 `dc_notion` 의 원본이라 지워도 됩니다.
`dls_fill.py` 에서 아래를 바꿉니다.

```python
import notion as nt                    # 지움
from dc_notion import Notion, read_value, build_value, is_empty
```

`nt.Notion(...)` 을 `Notion(...)` 으로,
`nt.read_value` 를 `read_value` 로 바꿉니다.
토큰을 인자로 넘기던 부분은 지워도 됩니다. 알아서 찾습니다.

**이수빈 · tg-notion-report**

`notion_safe_update.py` 에서 `notion_request` 함수만 바꿉니다.

```python
from dc_notion import Notion

_notion = Notion()

def notion_request(token, method, path, payload=None):
    return _notion._request(method, path, payload)
```

**판정 로직 743줄은 손대지 않습니다.**

**최현서 · skills**

`tools/notion.py` 에서 `_token` 과 `_call` 을 바꿉니다.

```python
from dc_notion import Notion, find_token

_n = Notion()

def _call(path, method="GET", body=None):
    return _n._request(method, path, body)
```

토큰 찾는 경로가 예전과 같습니다.

## 4. 랜섬 피드 바꾸기 — 안유빈

**dls-observatory / sources.py**

```python
RL_BASE = "https://api.ransomware.live/v2"      # 지움
LOOK_BASE = "https://www.ransomlook.io/api"     # 지움

from dc_ransomfeed import Fetcher, rl_groups, rl_country_victims, rl_victims, look_list, look_detail
```

주소를 만들던 자리를 함수로 바꿉니다.

```python
f"{RL_BASE}/groups"                 →  rl_groups()
f"{RL_BASE}/countryvictims/KR"      →  rl_country_victims("KR")
f"{RL_BASE}/victims/{y}/{m}"        →  rl_victims(y, m)
f"{LOOK_BASE}/{path}"               →  look_list(path)
```

`class Fetcher` 는 통째로 지우고 `dc_ransomfeed.Fetcher` 를 씁니다.
`get_json` 사용법이 같습니다.

**kr-leak-alarm**

```bash
git rm apps/kr-leak-alarm/collector/http_client.py
```

이 파일이 `dc_safety` 의 원본입니다.
`collector/sources/*.py` 맨 위를 바꿉니다.

```python
from ..http_client import SafeHttpClient          # 지움
from dc_safety import SafeHttpClient

BASE = "https://api.ransomware.live/v2"           # 지움
from dc_ransomfeed import rl_country_victims, rl_recent_victims
```

**두 축 분류와 대시보드는 손대지 않습니다.**

## 막히면

- 경로 오류 → `parents[2]` 숫자를 조정합니다
- import 오류 → 패키지 이름은 `dc_telegram` `dc_notion` `dc_safety` `dc_ransomfeed`
- 사용법 → `packages/<이름>/README.md`
- 실제 예시 → `apps/tg-korea-alert/check_login.py`

**앱 1개씩 합니다. 한 번에 여러 앱을 고치면 무엇이 깨졌는지 못 찾습니다.**

**텔레그램 2개가 우선입니다. 현재도 코드 분기가 진행 중입니다.**
