## 세 산출물이 공유하는 원칙

**하나. 근거가 확인된 것만 싣습니다.** 같은 종류라서 잇지 않고, 자료에서 관계가
확인된 경우에만 잇습니다. 모든 항목과 관계에 출처·관측일·신뢰도를 답니다.

**둘. 검증 상태를 세 단으로 나눕니다.** 이 구분이 지도와 가이드라인을 관통합니다.

| 상태 | 뜻 |
|---|---|
| 검증 완료 | 확보 자료·공식 확인·복수 근거로 실제 관련성이 확인된 것 |
| 검토 중 | 정황은 있으나 범위·신규성·귀속을 더 확인해야 하는 것 |
| 주장만 확인 | 게시물이나 행위자의 주장 외에 독립 근거가 부족한 것 |

**셋. 검증되지 않은 사건에는 구체적 대응을 만들지 않습니다.** 유출 항목이 확인되지
않았는데 조치를 자동 생성하면, 실제로 안 털린 항목까지 대응하게 만듭니다. 기관
안내문이 못 하는 부분이 정확히 여기입니다.

**넷. 도메인은 화면에 싣지 않습니다.** 포럼 **이름**은 써도 되지만 도메인은 안
됩니다. 스크린샷에 가림막을 씌우는 방식은 쓰지 않고, **데이터 원본에서 고친 뒤
다시 렌더**합니다. 어니언 주소·t.me 주소·조사 계정 아이디도 같습니다.

### 노션에 올린 것

산출물 DB에 확정안 페이지 둘을 만들고 위 파일들을 붙였습니다.

- **개인정보 유출 생태계 지도 — 확정안** · 프로토타입 스크린샷 + PDF 3개
- **유출 대응 가이드라인 — 확정안** · 화면 비교 사진 + PDF 2개

**노션 파일 한도는 5 MiB입니다.** 가이드라인 제안서(6.6 MB)는 이미지만
1500px·q72로 재압축해 1.2 MB로 줄여 올렸습니다. 텍스트는 손대지 않았습니다.
**배포용 HTML(8.1 MB)은 못 올립니다** — 본문이 gzip+base64 번들 한 덩어리라
줄일 여지가 없습니다. 공유 폴더에 두고 스크린샷만 올렸습니다.

### 스크린샷 처리

지도 화면 사진은 성민서 님 배포용 HTML의 **데이터 원본에서 도메인을 뗀 뒤**
다시 띄워 찍은 것입니다. 사진에 가림막을 씌우지 않았습니다.

- 쓰는 것 — `Downloads\투명배경_발표이미지쪽_생태계지도_예시.png`
- **쓰면 안 되는 것** — `Downloads\지도_컴셉비교\C_육각영토_프로토타입.png`
  (마스킹 전이라 `Cracked.io` 등이 그대로 보입니다)

가이드라인 화면 사진은 안유빈 님 미리보기 PDF의 시안 두 장을 원본 해상도
(791×545)로 뽑아 나란히 붙인 것입니다. 시안 자체가 이 해상도라 더 키우면
흐려집니다. 화면에 나오는 `NexaMall`은 시안용 가상 회사명입니다.
