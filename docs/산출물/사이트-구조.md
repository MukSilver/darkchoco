# 다크초코 사이트 — 구조 명세 (DC-SITE-001)

> 판 1.0 (2026-08-28). 세 최종 산출물을 한 웹사이트로 묶는 구조입니다.
> 지도·가이드라인·조사 자료가 공유하는 뼈대만 여기 적고, 각 산출물 고유의 내용은
> 각자의 시스템 명세서에 둡니다.
>
> 근거: 리서치 두 벌(사이트 구조 7에이전트 · 세 산출물 통합 5에이전트).
> 렌더링 스택(순수 SVG, 라이브러리 0개)은 앞선 판정에서 확정됐고 여기서 재론하지 않습니다.

## 1. 한 오리진 네 경로

```
example.com/          첫 화면      ┐
example.com/map/      생태계 지도   ├─ 정적. Cloudflare 엣지. 상시 PC와 무관
example.com/guide/    대응 가이드   │
example.com/wiki/     조사 자료     ┘
example.com/api/*     ──────────────  터널 → 상시 PC의 FastAPI
```

하위도메인으로 가르지 않습니다. 오리진이 갈리면 머리띠와 `?case=` 왕복이 어긋나고,
CORS 설정과 API 주소 분기가 생겨 운영·시연 두 벌 설정이 됩니다.

**배포 단위는 둘입니다.** `dc-site`(apps/site 전체) · `dc-wiki`(위키 Vite 빌드 산출물).
지도와 가이드를 쪼개지 않습니다 — 둘이 `assets/*`와 `data/*`를 공유하고 있어 쪼개면
그 경로의 주인이 없어집니다.

Workers 라우트로 붙입니다. 커스텀 도메인은 쓰지 않습니다 — Cloudflare가 DNS 레코드를
자기 것으로 만들어 터널 CNAME과 충돌합니다.

## 2. 가용성 — 서버가 죽어도 무엇이 사는가

| 구역 | 상시 PC 정지 시 |
|---|---|
| `/` `/map/` `/guide/` | **정상.** 엣지에 있고 PC와 무관 |
| `/wiki/` 목록·상세·원문·내려받기 | **정상.** 주 1회 구운 `snapshot.json`으로 |
| `/wiki/` 사전답변 질의 | **정상.** 사전답변을 스냅샷에 실음 |
| `/wiki/` 즉석 질의 | 중단 |

사라지는 것은 **즉석 질의 하나**입니다. 위키 프론트는 그리기 전에 `GET /api/status`를
찔러보고 실패하면 자유 질의 입력창만 잠급니다. `?view=stage`일 때는 아예 호출하지
않습니다 — 오프라인 시연에서 망을 한 번도 안 건드리게 합니다.

## 3. 경로 기준 — base 태그 금지

```js
// assets/shell.js — 항상 <사이트루트>/assets/ 에 있으므로 한 칸 위가 뿌리
export const BASE = new URL("../", import.meta.url).pathname.replace(/\/$/, "");
```

루트 배포·`/repo/` 하위·로컬 서버가 **같은 코드로** 맞습니다.

**`<base href>`는 404.html을 포함해 전 문서에서 금지합니다.** SVG의 `url(#id)`·
`use href="#id"`·문서 내 앵커를 base 기준으로 재해석해 파이어폭스·사파리에서
지도와 건너뛰기 링크가 깨집니다. 지금은 내부 참조가 없지만, 접근성 요구인
해칭 `<pattern>`을 넣는 순간 해당됩니다.

내부 링크에는 **끝 슬래시**를 붙입니다(`map/` — `map` 아님). GitHub Pages가
`/map`을 `/map/`으로 301 리다이렉트합니다.

## 4. 공통 셸 — mountShell(area)

`mountHead`를 `mountShell(area)`로 확장해 한 함수가 넷을 만듭니다.

1. 건너뛰기 링크 `a.skip[href="#main"]`
2. `header.shell-head`
3. `main#main`
4. `footer.shell-foot` — 「판 2026.09 · 기준일 2026-08-19 · 뽑은 시각」과
   `validate()`가 모은 problems를 「그리지 않은 요소 N개」 배지로

현재 구역 판정은 `href.includes(current)` 부분일치를 버리고 `id === area` 정확일치로
바꿉니다. `mountSampleWarning`은 각 페이지 호출을 없애고 `mountShell` 안으로 넣습니다
— 지금 지도는 import조차 하지 않아 구조적으로 경고를 달 수 없습니다.

**예시 데이터 판정을 뒤집습니다.** `meta.is_sample`이 정확히 `false`일 때만 경고를
안 답니다. 없거나 다른 값이면 예시로 간주합니다.

## 5. URL 상태 — 쿼리스트링이 유일한 진실

싣는 값 다섯: `case`(사고 id) · `place`(자리 id) · `k`(업종 칩, 쉼표) ·
`q`(검색어, 40자 상한) · `view`(stage).
호버·툴팁·패널 열림·viewBox 변환은 **싣지 않습니다.** 기본값이면 파라미터를 뺍니다.

| 무엇 | 어떻게 |
|---|---|
| 사고 선택 · 자리 선택 | `pushState` — 뒤로가기 한 번이 「방금 그 사고」 |
| 검색어 타이핑 · 칩 토글 | 250ms 디바운스 `replaceState` |
| Esc 해제 | depth>0이면 `history.back()`, 0이면 조용히 `replaceState` |
| 복원 | 항상 URL을 다시 파싱. `history.state`엔 depth 숫자 하나만 |

`assets/url-state.js`를 신설해 `readState/toSearch/commit/commitSoon/initHistory`를
모으고 다른 파일에서 `URLSearchParams`를 직접 만지지 않습니다.

최초 로드는 `popstate`가 뜨지 않으므로 `initHistory()` 후 `render(readState())`를
직접 부르고, `popstate`와 `pageshow(e.persisted)` 두 곳에서만 다시 그립니다.
`history.scrollRestoration = 'manual'`로 둡니다.

**q에 40자 상한을 두는 이유** — 한글 한 글자가 UTF-8 3바이트라 퍼센트 인코딩하면
9자가 됩니다. 40자면 360자이고 나머지를 합쳐도 2048자 안전선에 들어갑니다.

**줌·팬을 안 싣는 이유** — 휠 한 번에 `replaceState`가 수십 번 불려 사파리의
30초당 100회 제한에 걸리고, 빔프로젝터와 노트북의 화면 비율이 달라 좌표를
복원해도 다른 그림이 나옵니다.

없는 `case`/`place`는 오류로 처리하지 않고 조용히 떨어뜨리되 `replaceState`로
URL에서도 지웁니다. 안 지우면 그 사람이 다시 공유했을 때 같은 실패가 반복됩니다.

## 6. 데이터 — 쪼개지 않습니다

**실측이 근거입니다.**

| 파일 | 원본 | gzip | 압축률 |
|---|---|---|---|
| `leak-map.json` | 368,116 B | **15,354 B** | 4% |
| `guide.json` | 10,171 B | 2,937 B | 28% |
| `vocab.json` | 5,363 B | 1,912 B | 35% |

무명 자리 869개가 거의 같은 모양이라 압축률이 96%입니다. 분할 기준(gzip 100KB 초과)에
한참 못 미치므로 `map-core`/`cases` 2분할도 가이드 전용 `stats.json`도 만들지 않습니다.

- `tools/build_data.py`를 `separators=(',',':')`로 고정해 배포본에서 indent를 뺍니다 (256KB·gzip 13.7KB)
- `loadData`의 `cache:"no-store"`를 제거해 ETag/304를 씁니다 — 지금은 지도↔가이드를 오갈 때마다 새로 받습니다
- 캐시 무효화는 파일명 해시가 아니라 `assets/version.js`의 `DATA_V` 상수 하나
- 경로는 `assets/paths.js`의 `new URL('../data/…', import.meta.url)`
- 서비스워커는 넣지 않습니다. 오프라인은 로컬 서버(`serve.cmd`/`serve.sh`)로 풉니다

**`file://`로는 못 엽니다** — 모듈 CORS로 사이트가 통째로 안 뜹니다.
시연 절차서에 `http://127.0.0.1:8000/`으로 고정합니다.

## 7. 로딩 · 빈 · 오류 세 상태

`body`의 `data-state` 한 칸으로 `loading → ready | empty | error` 네 값만 씁니다.
HTML에 스켈레톤을 미리 넣고 `[data-state=loading]`에서만 보입니다.
887자리 배치 루프 전에 `await new Promise(r => requestAnimationFrame(r))`를 한 번
넣어 스켈레톤이 실제로 그려지게 합니다 — **병목은 파싱(1ms 미만)이 아니라 이 루프**입니다.

빈 상태 문안을 확정합니다.

1. 아직 안 고름 — 「왼쪽에서 사고를 고르십시오」
2. 검색 결과 0건 — 「걸리는 사고가 없습니다」
3. 사고 0건인 자리 — 「이름만 확보하고 아직 못 본 곳입니다」
4. 계약 위반으로 안 그린 요소 — 푸터 배지로 올리고 눌러서 폅니다

오류는 `shell.js`의 `fail(scopeEl, kind, detail)` 하나가 맡고 종류는
`network` / `contract` / `empty` 셋입니다. 문자열은 `innerHTML`이 아니라
`textContent`로 넣고, **`contract`는 데이터에서 온 값을 화면에 절대 찍지 않습니다**
— 지금은 `${e.message}`를 innerHTML로 꽂아 자리 id와 도메인 검출 메시지가
그대로 화면에 나옵니다.

## 8. 접근성 — SVG 안 tabindex 0개

**현재 위반**: `map/index.html`이 887개 `g`에 `tabindex="0" role="button"`을 답니다.
부모 SVG가 `role="img"`라 자식이 전부 presentational로 무시되어, 포커스는 가는데
접근성 트리에 이름도 역할도 없습니다 — **ACT 307n5z 위반, SC 4.1.2(레벨 A)**.
게다가 미조사 869곳은 `name` 필드가 없어 `aria-label`이 「undefined · 확인한 사고 1건」으로 나갑니다.

**해법은 role 교체가 아니라 포커스를 SVG 밖으로 빼는 것입니다.**

- SVG 안 `tabindex`를 **0개**로. SVG는 `role="img"` 유지 + `<title>`·`<desc>`를 `aria-labelledby`/`aria-describedby`로 묶음
- 클릭·포커스는 `investigated:true`인 **18곳**에만, SVG 위에 절대배치로 겹친 HTML `button` 18개(프록시)가 받음
- 프록시를 `role="group" aria-label="조사한 자리 18곳"`으로 감싸 **roving tabindex** (하나만 `tabindex=0`, 화살표는 기하 최근접, Home/End, Enter/Space, Esc 복귀, `aria-current="true"`)
- `role="grid"`와 `aria-activedescendant`는 쓰지 않음 — 육각 배치는 행·열이 어긋나 스크린리더가 없는 「행 3, 열 5」를 읽습니다
- 좌표는 `getBoundingClientRect` 차이로. `ResizeObserver`에 더해 **viewBox 재계산 직후에도 반드시 한 번** 부름
- 버튼 최소 24px 클램프(SC 2.5.8), 포커스 링은 CSS `outline`

**텍스트 대안은 필수입니다**(SC 1.1.1 A, Situation B). 다만 887행 표가 아니라
지도 아래 `<details>` 안 표 두 개 — 표 A(층·업종별 자리 수와 사고 수),
표 B(조사한 18곳). **미조사 자리 이름은 데이터에 없으므로 표에도 접근성 트리에도
올라가지 않습니다.**

라이브 리전은 둘만. `role="status"`에 필터·검색 결과 개수와 층 전환만
200~300ms 디바운스로, 로드 실패만 `role="alert"`. **사고·자리 선택은 라이브 리전을
쓰지 않고** 상세 패널 제목(`tabindex="-1"`)으로 포커스를 옮깁니다.

밀도·판정은 색만으로 구분하지 않고 테두리 두께 또는 해칭 `<pattern>`을 함께 바꿉니다.

## 9. 화면 · 발표 · 지면 세 벌

`tokens.css`가 CSS 변수 하나로 셋을 냅니다.

| 매체 | 켜는 법 | 무엇이 다른가 |
|---|---|---|
| 화면 | 기본 | — |
| 발표 | `?view=stage` (P 키 토글) | 글자·선 굵기·대비 키움, 머리띠·푸터 숨김 |
| 지면 | `@media print` | 흰 배경 팔레트, `@page A4 margin 14mm` |

`?case=12&view=stage`가 성립해야 합니다. 발표 모드를 별도 주소로 빼지 않습니다.

87mm는 `body.receipt` 또는 `@media print and (max-width:100mm)`에서
`@page { size: 87mm auto; margin: 4mm }`로 가릅니다. 육각형이 흰 칸으로 나오지 않게
`print-color-adjust: exact`를 넣습니다.

브레이크포인트를 **900px**(1열 전환)과 **1200px**(옆 패널 336px 고정) 둘로 통일합니다
— 지금 지도는 1100px, 가이드는 1000px로 제각각입니다.
`height: calc(100vh - 53px)`를 없앱니다 — 53px은 머리띠 높이를 손으로 잰 값이라
글자 크기가 바뀌면 어긋납니다.

## 11. 보안 — 헤더와 반출 게이트

meta CSP를 **단계로** 겁니다. 1단계:

```
default-src 'none'; script-src 'self'; style-src 'self' 'unsafe-inline';
img-src 'self'; connect-src 'self'; base-uri 'none'; form-action 'none';
upgrade-insecure-requests
```

`style-src`에서 `'unsafe-inline'`을 빼려면 인라인 `<style>` 네 곳과
`el(...,{style:"..."})` 14곳을, `require-trusted-types-for 'script'`는
`innerHTML` 14곳을 먼저 정리해야 합니다. **순서를 뒤집으면 발표 당일 화면이
조용히 빕니다.**

**저장소를 물리 분리합니다** — private 원본(노션 export, `build_data.py`,
화이트리스트, 미조사 원자료) / public 산출물. public은 히스토리를 새로 시작합니다.
한 번 커밋하면 삭제해도 git 히스토리와 raw에 남습니다.

배포 전 검사는 의존성 0개 `scripts/guard.mjs`(Node 표준 라이브러리만)로 돌리고
Actions required check와 pre-commit 훅에 같이 붙입니다.

1. 형태 정규식 — `.onion`, `.i2p`, `magnet:`, 지갑 주소, `t.me/`, 주민번호, 휴대폰, 이메일
2. 솔트 해시 대조 — `denylist.sha256`만 커밋, 솔트는 Actions secret
3. 스키마 불변식 — `investigated !== true`인데 `name` 키가 있으면 실패
4. `git ls-files` 화이트리스트
5. `git log -p --all` 히스토리 스캔

**실패 메시지에 걸린 값을 절대 에코하지 않습니다.** 파일:줄과 규칙 ID만 찍습니다.

## 12. `/wiki` 구역

**로그인을 두지 않습니다.** DC-WIKI-SYS-001이 확정한 문장입니다 —
「웹에 올리는 것은 전부 공개 가능 자료다. 비반출 자료는 노션에만 두고 필요한
사람에게 따로 전달한다.」

> **정정 기록.** 이 사이트의 초기 설계는 `/wiki`를 「팀 계정이 있어야 열림」으로
> 잡았습니다. RAG DB 명세를 읽지 않고 세운 전제였고, 명세와 정면으로 어긋납니다.
> 2026-08-28에 네 곳(첫 화면 문·설명·위키 페이지·README)에서 걷어냈습니다.

스택은 React + Vite + TS + Tailwind(명세 확정). `apps/wiki-web`에 새로 만들고
`base:'/wiki/'`로 빌드합니다. 빌드 산출물을 `apps/site` 안에 넣지 않습니다.

**공유하는 것은 셋뿐입니다.**

1. **토큰** — `apps/site/assets/tokens.css` 한 벌. 위키는 Tailwind 번들보다 먼저
   같은 파일을 link하고 진입 CSS에서 `@theme inline`으로 이름만 잇습니다
   (`--color-bg: var(--bg)`). **`inline`은 선택이 아닙니다** — 붙여야 `bg-panel`이
   `var(--panel)`로 컴파일되어 `body.present`와 `@media print` 덮어쓰기가
   React 안에서도 듣습니다
2. **머리띠** — JSX로 다시 만들지 않고 `shell.js`의 `mountShell`을 `createRoot` 전에 부릅니다
3. **공통 키** — `places[].id`와 `cases[].id`

**컴포넌트는 절대 공유하지 않습니다.** CI에서 `tokens.css` 바깥의 색 하드코딩을
grep으로 잡습니다.

## 13. 구역 간 연결 셋

- **(A) 사고 상세를 교차로로.** `/guide/?case=N`이 세 구역이 모이는 자리입니다.
  확인된 항목 → 조치 → 그 사고의 경로만 그린 축소지도(`hex.js` 재사용) →
  「어떻게 확인했나」 접힘 블록
- **(B) 지도 자리 → 위키는 질문 칩으로만.** 자유 입력 프리필을 만들지 않습니다.
  미리 만든 질문 두세 개를 칩으로 달고 `/wiki/?place=<id>&q=<질문id>`로.
  **이 질문들의 답은 사전답변에 미리 채워 둡니다** — 발표 중 SSE도 과금도 지연도
  없습니다. 칩은 반출 표시가 붙은 자리에만 답니다
- **(C) 위키 인용 → 지도.** 표준문서 메타에 `places[]`·`cases[]`를 넣고 인용 줄마다
  「지도에서 보기」를 `/map/?place=<id>`로

**가이드 → 위키 직결은 만들지 않습니다.** 일반인 동선에 다크웹 문서를 끼우지 않습니다.

키 계약을 검사로 못박습니다 — 주 1회 색인 배치에서 문서 메타의 id가
`leak-map.json`에 없으면 **색인을 거부합니다.** 없으면 반년 뒤 링크가 조용히 깨집니다.

## 14. 비용 방어 다섯 겹

1. Anthropic 콘솔 자체 지출 상한 **$60**
2. 요청당 비용을 상수로 — `max_tokens=1024`, 질문 500자 상한, 검색 조각 8개 고정.
   모델은 `claude-sonnet-5`로 못박음(날짜 접미사 없음). **thinking을 끄거나
   `effort=low`** — 그냥 두면 adaptive로 돌아 출력이 추정치를 넘습니다
3. 제한은 FastAPI 안에 — Cloudflare 무료 레이트리밋은 zone당 규칙 1개·10초 창
   고정이라 초당 1회 크롤러도 못 막습니다. SQLite 사용량 테이블로 IP당·전체 한도
4. UI-04 질의 폼에 **Turnstile**, 서버에서 토큰 검증 후에만 Claude 호출
5. **사전답변 먼저 조회.** 있으면 API를 안 부릅니다. Batch API(50% 할인)로 미리 구움

프롬프트 캐시는 기대를 낮춥니다 — 매번 바뀌는 것이 검색 조각이라 캐시되는 것은
시스템 프롬프트뿐이고 절감폭은 10%대입니다.

## 15. 기각한 것

| 무엇 | 왜 |
|---|---|
| A·B를 React로 다시 짜기 | 실측 1,156줄을 사실상 전부 재작성. 채점 대상 완성품을 발표 직전에 「작업 중」으로 |
| C를 바닐라로 다시 짜기 | 확정된 16쪽 명세 재발행 + TypeScript 상실. 이음매가 URL 하나라 통일 효과가 작음 |
| 전체를 Vite MPA로 | A·B의 무빌드 제약이 깨짐. 발표 당일 남의 노트북에서 `npm ci`가 실패할 수 있음 |
| `leak-map.json` 분할 | gzip 15KB. 분할 기준(100KB)에 한참 못 미침 |
| 파일명 해시 캐시 무효화 | Pages의 `max-age=600`을 못 바꿔 해시를 박아도 캐시 수명이 그대로 |
| 서비스워커 | 요구의 실체는 「망 없이 뜬다」이고 로컬 서버가 충족. `file://`은 어차피 못 씀 |
| `<base href>` | SVG 내부 참조·문서 앵커를 재해석해 파이어폭스·사파리에서 깨짐 |
| 해시 라우팅 | 무빌드에서 라우팅·포커스·스크롤·제목을 직접 짜야 하는데 얻는 것 없음 |
| `index.html`을 지도로 교체 | `?case` 왕복과 인쇄물·QR 주소가 전부 `/map/` 기준. 유출 피해자가 처음 만나는 화면이 887칸 벌집이 됨 |
| `role="grid"` / `graphics-document` | 육각 배치는 행·열이 어긋나 없는 「행 3, 열 5」를 읽음. 문제는 role이 아니라 내부 tabindex |
| 887행 텍스트 대안 표 | 지도가 전하는 것은 「어디에 얼마나 몰렸나」. 미조사 869곳은 name이 없어 나열 불가 |
| JS 비밀번호 복호화 | 암호문·솔트·코드가 전부 클라이언트. 오프라인 무제한 시도 가능하고 접근 로그가 없음 |
| Trusted Types·`style-src 'self'` 지금 켜기 | `innerHTML` 14곳·인라인 style 14곳이 남아 있어 발표 당일 화면이 조용히 빔 |
| Worker 셋으로 쪼개기 | 지도·가이드가 `assets/*`·`data/*`를 공유해 그 경로의 주인이 없어짐 |
| `/wiki/*`를 터널로 | 위키의 정적 화면까지 PC와 함께 죽음. 번들은 PC에 묶일 이유가 없음 |
| 서브도메인 분리 | CORS와 API 주소 분기가 생겨 운영·시연 두 벌 설정이 됨 |
| Pages + Functions / 단일 Worker 프록시 | 배포가 한 덩어리로 묶이고 SSE 경로에 부품이 하나 늘어남 |
| 발표 때만 서버 켜기 | 아끼는 돈 월 3,300원. 대가는 발표 당일 아침 첫 고장 |
| 첫 방문 안내 오버레이 | 아무도 안 봄. 링크 글자 자체를 설명으로 |
