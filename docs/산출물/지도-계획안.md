## 2. 결정 이력 — 왜 2층인가

1. 성민서 영토판이 처음에 떨어진 진짜 이유는 그림이 아니라 **오픈웹이 들어갈 자리가 없다**는
   것이었습니다. 영토가 업종으로 나뉘면 「접근성」이라는 축이 사라집니다.
2. 노드-링크 그래프(금정현 v7)로 바꾸면 오픈웹은 들어오지만 **면적 은유를 잃고**,
   자리가 887개가 되는 순간 털뭉치가 됩니다.
3. 해법: **세계를 위아래 두 층으로 가릅니다.** 위가 오픈웹, 아래가 다크웹.
   업종 대륙은 층 안에서 유지됩니다. 두 층이 같은 격자를 써서 같은 (col,row)가
   화면에서 위아래로 정확히 겹칩니다 — 층간 이동선이 수직으로 읽히는 이유입니다.
4. 투영은 원근이 아니라 **평행 기울임**(x전단 0.60 · y압축 0.345)입니다.
   앞에 있어도 뒤에 있어도 같은 면적은 같게 보입니다. 면적=사고 수라는 약속을
   지키려면 원근을 쓸 수 없습니다.
5. 층 사이 간격은 데이터가 아닙니다. 판 두께도 데이터가 아닙니다. 이 둘은
   「두 세계가 분리되어 있다」는 사실 하나만 나릅니다.
