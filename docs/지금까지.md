## 1. 통합 크롤러가 무엇인가

**명부를 채우는 도구입니다.** 노션 다크웹 DB 세 개(포럼 · 텔레그램 ·
랜섬웨어)에 811줄이 있는데, 칸이 24~30개씩이고 대부분 비어 있었습니다.
그 칸을 기계가 채웁니다.

### 「명부」와 「사건 기록」은 다릅니다

같은 「크롤링」이라는 말을 쓰지만 채우는 곳이 다릅니다. 이걸 헷갈리면
남의 데이터를 지웁니다.

| | 크롤러 `dc.py crawl` | 수집기 `dc.py run` |
|---|---|---|
| 채우는 곳 | 다크웹 DB 세 개 | 수집·검증 DB |
| 묻는 것 | **어디가 있고 살아있나** | **무슨 글이 올라왔나** |
| 한 줄 | 한 곳 | 한 사건 |

크롤러는 수집·검증 DB 를 안 건드립니다. 반대도 마찬가지입니다.

### 명령 하나

```bash
python dc.py crawl              # 미리보기. 노션에 안 씁니다
python dc.py crawl --apply      # 실제로 씁니다
python dc.py crawl --only forum --limit 5
```

### 코드가 어디 있나

```
hub/
├── places/                    「어디가 있고 살아있나」 → 다크웹 DB 3개
│   ├── run.py       475줄       세 갈래를 돌리고 표를 냅니다
│   ├── write.py     274줄     ★ 노션에 쓰는 유일한 곳 (관문 5개)
│   ├── place.py     351줄       Place · 칸 다루는 법 3가지
│   ├── egress.py    211줄     ★ 밖으로 나가는 유일한 길 (Tor 관문)
│   ├── probe/                   갈래마다 조사기 하나
│   │   ├── forum.py    631줄      포럼 (랜섬도 이걸 씁니다)
│   │   ├── ransom.py   334줄      ransomware.live API
│   │   └── telegram.py 271줄      공개 미리보기
│   └── extract/                 본문에서 뽑아내는 것
│       ├── links.py    186줄      연결된 곳
│       ├── boards.py   147줄      유통 자리 · 개인정보 유출
│       └── lang.py      78줄      사용 언어
│
├── events/                    「무슨 글이 올라왔나」 → 수집·검증 DB
│   ├── run.py                   어댑터를 돌립니다
│   ├── registry.py              sources/ 를 훑어 목록을 만듭니다
│   ├── contract.py              어댑터 계약 (Item · Needs · Skip)
│   └── sources/
│       ├── ransom_kr.py           kr-leak-alarm 을 부릅니다
│       └── tg_preview.py          skills/collect 를 부릅니다
│
└── sched.py                   주기 · 둘이 같이 씁니다
```

한 줄이 지나는 길입니다.

```
노션 한 줄
   │
   ▼ ① notion.줄들()      주소 · 어니언 · 이름을 꺼냅니다
   ▼ ② egress.오프너()   Tor 가 없으면 여기서 멈춥니다
   ▼ ③ forum.한곳()       클리어넷 → 죽으면 어니언으로 다시
   ▼ ④ place.노션값()     칸마다 다루는 법이 다릅니다 (아래 §2-3)
   ▼ ⑤ notion.반영()      관문 5개를 다 지나야 씁니다
   │
   ▼ 기본은 미리보기. --apply 를 줘야 실제로 씁니다
```

무엇이 무엇을 부르는지 자세한 것은 [흐름.md](흐름.md) 에 있습니다.

## 2. 지킨 규칙 셋

이 셋이 이 도구의 전부입니다. 고칠 때 이걸 깨면 안 됩니다.

### ① Tor 가 없으면 아예 안 나갑니다

다크웹 쪽을 여는 것은 **저쪽 로그에 우리 주소를 남기는 일**입니다.
그게 한국 주소면 우리가 누구인지 좁혀집니다.

`probe/egress.py` 가 밖으로 나가는 유일한 길입니다. Tor 가 안 떠 있으면
요청을 만들지 않고 예외를 냅니다. `ExcludeExitNodes {kr}` 로 한국 출구도
뺐습니다. 이걸 우회하는 코드가 새로 들어오면 `test_맨IP금지.py` 12개가
깨집니다.

**윈도우에서 그냥 돌리지 마십시오.** 다크웹 쪽이 그 PC 로 내려오고 V3 가
막습니다. VM 이나 WSL 에서 돌립니다.

### ② 노션 스키마를 안 바꿉니다

칸도 선택지도 안 늘립니다. 저 DB 가 LLM 위키의 근간이라 바뀌면 안 됩니다.
`write.py` 가 노션에서 스키마를 읽어 와서, 없는 칸과 없는 선택지를
**보내기 전에** 거릅니다.

### ③ 사람이 쓴 칸은 기계가 안 덮습니다

기계가 만지는 칸이 18개인데 다루는 법이 셋으로 갈립니다.

| 다루는 법 | 칸 | 뜻 |
|---|---|---|
| 덮어쓰기 | 상태 · 확인일 · 주소 · 어니언 주소 · 최근 활동 | 기계 소관. 볼 때마다 새 값 |
| 합치기 | 규모 · 피해 대상 · 한국 관련 유출 | `(YYYY-MM-DD 기준)` 으로 끝나는 기계 줄만 갈아 끼움 |
| 빈칸만 | 사용 언어 · 들어가는 법 · 어떤 곳인지 · 연결된 곳 외 10칸 | **사람이 썼으면 안 건드림** |

「상태」가 이미 `압수됨` · `인계됨` 이면 기계가 안 덮습니다. 그건
「살아있나」가 아니라 「무슨 일이 있었나」라서 사람이 판정한 값입니다.

담당자 · 순위 · 웹에 올림 · DB 반영 · 비고는 아예 안 씁니다. 팀 운영
칸입니다.

## 3. 실측 — 8/29 미리보기 (노션에 안 씀)

VM 안에서 Tor 로 39분 걸렸습니다.

| 갈래 | 본 줄 | 연 곳 | 바뀔 줄 | 상태 |
|---|---:|---:|---:|---|
| 텔레그램 | 18 | 11 | 10 | online 11 · 미확인 7 |
| 포럼 | 261 | 97 | 119 | 미확인 161 · online 97 · offline 3 |
| 랜섬웨어 | 507 | 159 | 299 | offline 261 · online 159 · 미확인 87 |
| **합** | **786** | **267** | **428** | |

곁들여 나온 것입니다.

- **명부에 없는 이웃 345곳**을 봤습니다. 명부에 있는 곳들이 서로 링크로
  가리키는 주소인데, 우리 명부에 없는 것들입니다. 노션에 안 씁니다
- 「연결된 곳」은 **우리 명부에 이미 있는 곳**만 적습니다. 처음 보는 주소는
  관계가 아니라 잡음입니다. 여기서 생태계 지도의 선이 나옵니다
- BreachForums 는 어니언 미러를 찾아서 제목까지 맞췄습니다
- 압수 안내로 바뀐 곳 6군데는 **사람이 손으로** `압수됨` 처리해야 합니다.
  포럼 DB 에 그 선택지가 없어서 기계가 못 씁니다

검사는 `packages/tests/` 에 **174개**입니다. 전부 표준 라이브러리로 돕니다.

```bash
for f in packages/tests/test_*.py; do python "$f"; done
```

## 4. 아직 안 한 것

정직하게 적습니다. 이걸 다 했다고 생각하고 다음 작업을 잡으면 겹칩니다.

### ⛔ DLS 통합 — 안 했습니다

`apps/dls-observatory/dls_fill.py` (안유빈 님) 는 **지금도 손으로 돌립니다.**
`dc.py auto` 가 안 부릅니다. `hub/events/sources/` 에는 `ransom_kr.py` 와
`tg_preview.py` 둘뿐입니다.

이번 판에서 dls 쪽에 한 것은 **안전 손질 다섯 가지뿐**입니다.

| 무엇 | 왜 |
|---|---|
| 「한국 관련 유출」에서 피해 기관 이름을 뺐습니다 | 크롤러는 건수만 씁니다. 한쪽만 이름을 적으면 규칙이 갈립니다 |
| `압수됨` · `인계됨` 을 안 덮게 했습니다 | 크롤러와 같은 규칙 |
| 선택지에 없는 값을 안 보내게 했습니다 | `infer.py` 가 노션에 없는 값을 냅니다 |
| 「국가」 칸을 껐습니다 | 그 선택지가 랜섬 DB 에만 있습니다 |
| Tor 를 타게 했습니다 | 같은 API 를 두 도구가 치는데 한쪽만 맨 IP 로 나가고 있었습니다 |

**붙일 때 정할 것이 남아 있습니다.**

- 열쇠가 어긋납니다. dls `lockbit3` · `alphv` · `clop` vs kr `lockbit` ·
  `blackcat` · `cl0p`. 지금 `group_key` 로 조인하면 큰 그룹이 안 붙습니다
- `victims` 표에 `attackdate` 칸을 둘지. dls 는 공격일과 공개일을 따로
  두는데 kr 은 하나에 밀어 넣습니다
- 랜섬 갈래에서 **피해 집계를 껐습니다.** dls_fill 이 이미 그 칸들을
  채우는데 꼴이 달라 서로 갈아 끼우지 못하고 줄이 쌓였습니다.
  붙이려면 꼴부터 맞춰야 합니다

수익률이 낮아서 우선순위를 내렸습니다. 120줄 중 6줄만 바뀝니다.

### ⛔ 「연결이 안 됩니다」 461줄

포럼 125 + 랜섬 336 입니다. 이게 지금 가장 큰 덩이입니다.
**offline 이 아닙니다.** 그래서 상태를 안 바꿉니다.

랜섬 쪽은 진짜 죽은 게 많아서 offline 261 이 맞을 가능성이 큽니다.
포럼 125 는 아직 왜인지 안 갈랐습니다.

### ⛔ 차례표 등록

`python dc.py install-task` 를 아직 아무도 안 걸었습니다. 지금은 사람이
손으로 부릅니다. 명령은 만들어져 있고 `--show` 로 볼 수 있습니다.

### ⛔ forum-crawler selector

성민서 님 것입니다. 뼈대만 있습니다. 통합 크롤러의 「첫 화면 한 장」과
겹치지 않습니다.

| 갈래 | 가벼운 확인 (자주) | 깊은 조사 (가끔) |
|---|---|---|
| 포럼 | `probe/forum.py` 첫 화면만 | `apps/forum-crawler` 도커·로그인 |
| 랜섬 | `probe/ransom.py` 상태만 | `apps/dls-observatory/dls_fill.py` |
| 텔레그램 | `probe/telegram.py` 공개 미리보기 | `skills/collect` 실계정 |
