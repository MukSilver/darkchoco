## 3. 통합 크롤러

### 구성

```
hub/places/
  run.py             갈래표 하나로 세 갈래 실행
  egress.py          Tor 관문. 외부 접속의 유일한 경로
  fetch.py           여는 법 3종 — http · browser · api
  merge.py           조사기 여럿의 결과를 한 줄로 병합
  backoff.py         연속 실패한 대상 제외
  write.py           노션 기록. 검증 5단계
  place.py           Place 자료 구조
  infer.py           분류 판정
  probe/             forum · ransom · telegram
  collect/           수집기 7종 + 호출 순서
  extract/           links · boards · lang · page

hub/events/
  run.py · registry.py · contract.py
  sources/           tg_preview
  telegram/          채널 수집 · 분석 · 노션 보고서 9종
```

### 실행

```bash
python dc.py crawl              # 미리보기 (기본값)
python dc.py crawl --apply      # 노션 반영
```

기본 동작은 미리보기입니다. `--apply` 를 지정해야 기록합니다.

### 준수 규칙 셋

| # | 규칙 | 강제 지점 |
|---|---|---|
| ① | Tor 미경유 시 요청 차단, 한국 출구 노드 제외 | `egress.py` |
| ② | 노션 스키마 변경 금지 | `write.py` |
| ③ | 수동 입력 값 보존 | `place.py` |

`압수됨` 과 `인계됨` 은 사람이 판정합니다. 기계는 덮어쓰지 않습니다.

| 삭제한 앱 | 줄 | 흡수 위치 |

| `forum-crawler` | 3,909 | `places/collect/` |

### 흡수하지 않은 것

| 항목 | 판단 |
|---|---|
| 로그인 (`login_session` · `session_manager`) | 미수행 결정. 계정 필요 및 흔적 증가 |
| MD 리포트 생성기 2종 | 노션 직접 기록으로 대체 |
| `whitelist.yaml` | 폐기. 명부 등재를 승인으로 간주 |
| `tor_probe` 의 SOCKS5 터널 | `egress.py` 로 대체. 경로 이중화 방지 |

`notion_safe_update.py` 739줄은 한 글자도 변경하지 않았습니다. AST 비교로
확인했습니다.

## 6. 8/30에 확인한 사실 넷

전부 오류를 발생시키지 않는 문제였습니다.

| 사실 | 발견 경로 |
|---|---|
| 브라우저가 차단을 우회하지 못함 (browser 전용 성공 0건) | http와 병행 측정 |
| 한 줄에 노션을 두 번 기록 | 12줄 조사에 「바뀐 줄 14」 |
| 브라우저 컨텍스트 누수 | VM 5시간 46분 정지 |
| `parents[N]` 깊이 불일치 | 8/30에 추가한 검사가 검출 |

각 사실은 검사로 고정했습니다.
