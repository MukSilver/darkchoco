# 다크초코 대시보드 (M1)

수집 현황과 노션 사건을 한 화면에서 봅니다. 탭 둘입니다.

    [제어판]   수집 표 현황 · 최근 실행 · 설정 점검 · 자주 쓰는 명령
    [사건]     노션 수집 DB 줄. 검토 여부 · 소스 · 한국 관련으로 거른다

## 쓰는 법

```bash
python apps/dash/serve.py
```

굽고 나서 `http://127.0.0.1:8787` 을 브라우저로 엽니다. 굽지 않고 있는 것만 보려면
`--no-build`, 노션을 안 읽으려면 `--no-notion` 을 줍니다.

## 왜 굽나

화면은 각자 PC 에서 뜨고 데이터는 노션에 있습니다. 브라우저가 노션을 직접 부르면
**토큰이 브라우저에 있어야 합니다.** 토큰은 최현서 권한으로 돌고 팀원에게 넘기지
않는 것이 규칙입니다. 그래서 `build.py` 가 한 번 읽어 파일로 굽고 화면은 그 파일만
읽습니다. 토큰은 굽는 자리에만 있습니다.

## 하는 것

**O / X 를 눌러 노션에 바로 반영합니다.** 서버가 대신 씁니다. 토큰은 서버 자리에만
있고 브라우저에 안 갑니다. 쓰는 것은 「검토 여부」 와 그에 딸린 「DB 반영」 둘이고,
값은 셋만 받습니다.

**「DB 반영」 은 화면이 고르지 않습니다.** 검토가 바뀌는 방향을 보고 서버가 맞춥니다
(2026-09-23). 「DB 반영」 은 지도 · RAG · 가이드가 같이 보는 공개 스위치입니다.

    미검토 · 사건 X → 사건 O     켠다
    사건 O · 빈칸  → 사건 O     안 건드린다   일부러 꺼 둔 것을 되살리지 않는다
    무엇이든      → 사건 X     끈다
    무엇이든      → 미검토     끈다

규칙은 `api.py` 와 `deploy/worker.js` 에 두 벌 있습니다. `packages/tests/test_공개규칙.py`
가 둘이 같은지 봅니다.

**포럼 사건 줄을 새로 만듭니다** (2026-09-23 · 수집 여섯 칸 중 마지막 칸). 포럼 킷이 낸
「칸 값」 을 「포럼 사건 올리기」 가 받아 미리 보이고, **사람이 고르고 누를 때만**
`/api/forum-rows` 가 수집 DB 에 미검토 · 공개 꺼짐으로 올립니다. 들어오는 길은 셋입니다 —
킷이 이 창을 열어 넘기기(호스트) · 칸 파일(.json) 끌어다 놓기(VM) · 붙여넣기.

- **본문은 안 받습니다.** 제목 · 주소 · 게시자 · 날짜 · 게시판 · 한국 신호뿐이고, 모르는 키는 버립니다
- UID 는 옛 길(`kit_in.py` → `push.py`)과 같은 꼴입니다. UID 나 원문 주소가 같은 줄이 있으면 안 만듭니다
- 한 번에 20줄씩 보냅니다. 무료 요금제의 요청당 바깥 요청 50번 상한 밑에 둔 것입니다
- 로컬 `api.py` 와 배포 `worker.js` 두 벌입니다. `packages/tests/test_포럼사건.py` 가 둘과 옛 길을 맞춰 봅니다

**정해진 일감을 눌러 돌립니다.** 수집 한 바퀴 · 집계처 한 판 · 관측 가져오기 ·
다시 굽기 같은 것들입니다. 로그가 화면에 그대로 올라옵니다.

## 안 하는 것

**임의 명령을 실행하지 않습니다.** 화면은 일감 **열쇠만** 보내고 무엇을 돌릴지는
`run_jobs.py` 가 정합니다. 목록에 없는 것은 못 돌리고 화면이 인자를 못 넣습니다.
셸도 안 거칩니다. 제어판(`skills/run.py`)이 메뉴에서 고르면 미리 정해진 명령이
도는 것과 같은 구조입니다.

**한 번에 둘을 안 돌립니다.** 같은 표에 둘이 쓰면 줄이 뭉칩니다.

**명부 셋(포럼·랜섬웨어·텔레그램)을 다시 그리지 않습니다.** 노션이 정본이라
화면을 새로 만들면 사본이 하나 더 생깁니다. 고치는 것은 노션에서 합니다
(2026-09-07 결정, 프젝 `DEV.md` 판단 기록).

**배포판에는 일감 돌리기가 없습니다.** 남의 서버는 이 PC 의 수집기를 못 돌립니다.
그쪽에서는 명령을 복사만 합니다.

**본문과 개인정보 값은 안 담습니다.** 굽는 파일이 브라우저에 뜨고 디스크에 남습니다.
수집 DB 에 본문 칸이 없는 것과 같은 이유입니다.

## 자리

    build.py        노션 + 수집 표 → data/dash.js
    api.py          화면이 부르는 자리. 검토 여부 쓰기 · 일감 돌리기
    run_jobs.py     돌릴 수 있는 일감 목록. **여기 있는 것만 됩니다**
    serve.py        127.0.0.1 에만 붙는 정적 서버
    index.html      화면 한 장
    data/dash.js    구운 것. **git 에 안 올라갑니다** (대상 조직명이 들어 있습니다)
