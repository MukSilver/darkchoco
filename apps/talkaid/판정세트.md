    무엇      한국어 문장 예순셋. **번역이 나아졌는지 재는 자**
    왜        「스무 문장 중 넷이 틀렸다」가 유일한 기준선인데 재현할 수가 없었다.
             모델을 바꾸든 프롬프트를 바꾸든 나아졌다고 말하려면 같은 것을 다시 재야 한다

**공개 벤치마크로는 이걸 못 잰다.** BLEU·COMET 은 코퍼스 수준 연속 점수라
「채팅 문장 스무 개 중 몇 개가 뜻이 틀리나」에 답하지 못한다. 직접 만드는 수밖에 없다.

## 쓰는 법

    python 판정.py 돌리기 opus            판정결과/opus.md 가 나온다
    (사람이 그 파일을 열어 각 줄에 O · X · ~ 를 적는다)
    python 판정.py 세기 opus              몇 개가 맞았나
    python 판정.py 견주기 opus gemma      두 판을 나란히

## 무엇으로 가르나

    O   뜻이 맞다.  보내도 된다
    X   **뜻이 틀렸다.**  보내면 조사가 망가진다
    ~   뜻은 맞는데 어색하다.  상대가 눈치챈다

**O 와 X 의 경계는 「보내도 되나」다.** 문법이 조금 어긋나거나 관사가 빠진 것은 O 다.
질문이 평서문이 되거나 주어가 바뀌거나 빠진 낱말이 있으면 X 다.

## 고칠 때

문장을 **지우지 않는다.** 지우면 옛 결과와 못 견준다. 늘리기만 한다.
줄 순서도 바꾸지 않는다. 번호가 결과 파일의 열쇠다.
