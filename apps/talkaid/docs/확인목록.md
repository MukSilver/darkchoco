# 손으로 확인하는 것 열여섯

시험 마흔아홉 묶음이 도는데도 여기 목록이 따로 있는 까닭은, **시험이 창을 안 띄우고
모델을 안 올리기 때문**이다. 시험이 지키는 것은 자료와 순수 함수이고, 아래는 사람이
눌러 봐야 알 수 있는 것이다.

    python tests/test_bag.py · test_engine.py · test_talkaid.py · test_ui.py

**넘겨주기 전과 exe 를 다시 지은 뒤에 밟는다.** 판정 칸에 O · X · ~ 를 적는다.

이 파일은 2026-09-23 에 만들었다. 전에는 이 목록을 대화로만 주고받아서 다음 세션에
사라졌다. 기능이 늘면 여기에 줄을 더한다.

---

## 처음 받는 사람 흉내 (1~3)

| | 무엇을 하나 | 무엇이 보여야 하나 | 판정 |
|---|---|---|---|
| 1 | `.venv` 폴더를 지우고 `scripts\run.bat` 을 더블클릭한다 | venv 를 만들고 pip 를 깔고 모델 2.9GB 를 받은 뒤 **창이 저절로 뜬다.** 검은 cmd 창은 남지 않는다 | |
| 2 | 그 과정에서 멈추지 않는지 본다 | `UnicodeDecodeError: 'cp949'` 가 안 나야 한다. 2026-09-23 에 `requirements.txt` 첫 줄에서 여기가 멈췄다 | |
| 3 | 창이 뜬 뒤 「▸ 로그」를 편다 | 모델 받은 진행률이 쌓여 있다. `~/.config/darkchoco/talkaid.log` 에도 같은 것이 있다 | |

## 단축키 셋 (4~6)

창을 띄워 둔 채 **다른 프로그램**(메모장이면 된다)에서 한다.

| | 무엇을 하나 | 무엇이 보여야 하나 | 판정 |
|---|---|---|---|
| 4 | 한국어를 골라 `Ctrl+C` → `Ctrl+Alt+1` → 메모장에 `Ctrl+V` | 영어가 붙는다. 창에는 **역번역이 같이 뜬다** | |
| 5 | 영어를 골라 `Ctrl+C` → `Ctrl+Alt+2` | 한국어가 붙는다. 중국어로도 해 본다 — 알아서 가른다 | |
| 6 | `Ctrl+Alt+3` | 사이드바가 열리고 닫힌다 | |

## 번역칸 (7~9)

| | 무엇을 하나 | 무엇이 보여야 하나 | 판정 |
|---|---|---|---|
| 7 | 창에 **「이중 갈취를 늘 쓰시나요」**를 치고 `Ctrl+Enter` | `Do you often use double extortion?` **물음표로 끝나야 한다.** 평서문(`Double extortion is often used.`)이면 사전 자리 고침이 안 실린 것이다 | |
| 8 | **「방탄호스팅은 어디를 쓰시나요」** | `Where do you use bulletproof hosting?` 명사를 앞에 던진 꼴(`Bulletproof hosting where do you use it?`)이면 옛 판이다 | |
| 9 | **「I am interested.」**가 되는 한국어를 넣는다 (「관심 있습니다」) | `I'm interested` — **끝 마침표가 없고 줄여 썼다** | |

## 채팅 축약 (10)

| | 무엇을 하나 | 무엇이 보여야 하나 | 판정 |
|---|---|---|---|
| 10 | 창 아래 `u · ur` 를 켜고 「당신은 무엇을 원하나요」류를 옮긴다. 그다음 끄고 다시 | 켜면 `you` → `u`. **문장 첫 낱말은 켜도 안 바뀐다.** 기본은 꺼져 있어야 한다 | |

## 상용구와 자루 (11~14)

| | 무엇을 하나 | 무엇이 보여야 하나 | 판정 |
|---|---|---|---|
| 11 | 사이드바에서 [상용구] | 갈래 머리글이 찍힌다. **공통에 `── 짚기` 가 되묻기 바로 아래 있다** | |
| 12 | **상대를 안 고른 채** [복사]를 두 번 | **붉은 알림**이 뜨고 늘 첫 변형만 나간다. 틀린 초록불이 빨간불보다 나쁘다 | |
| 13 | 상대를 고르고 같은 줄의 [복사]를 자루 크기만큼 | **한 바퀴 안에 안 겹친다.** 다 쓰면 다시 섞이는데 첫 장이 직전 마지막과 안 같다 | |
| 14 | 상대를 `2` 에서 `3` 으로 바꾼다 | 자루가 갈린다. **그리고 사이드바에 옮겨 둔 번역 결과가 안 날아간다** — 2분 들여 옮긴 질문지가 드롭다운 한 번에 사라지면 대화 중 제일 아픈 사고다 | |

## 창과 배포 (15~16)

| | 무엇을 하나 | 무엇이 보여야 하나 | 판정 |
|---|---|---|---|
| 15 | 「항상 위」를 껐다 켠다 | 다른 창을 눌렀을 때 가려지고, 다시 켜면 위로 온다 | |
| 16 | **exe 를 다시 지었으면** `dist\talkaid\_internal\` 의 `terms.json` · `snippets.json` · `en_style.json` 을 레포와 견준다 | 셋이 바이트까지 같다. **exe 옆 파일이 이긴다** — 옛것이 남아 있으면 exe 만 옛 규칙으로 돈다 | |

## 자동으로 못 보는 까닭

| 항목 | 왜 시험이 못 잡나 |
|---|---|
| 1~3 | venv 와 모델 내려받기는 시험이 안 건드린다 |
| 4~6 | `RegisterHotKey` 는 실제 창이 있어야 걸린다 |
| 7~9 | 모델을 올려야 한다. 시험은 400ms 와 인터넷을 아끼려고 안 올린다 |
| 11~14 | tkinter 창과 클립보드가 필요하다. `test_ui.py` 는 자료 구조만 본다 |
| 16 | 지은 exe 는 레포 밖에 있다 |

**7·8 은 특히 사람이 봐야 한다.** 번역 품질은 시험이 원리상 못 잡는다 — 무엇이
맞는 영어인지 코드가 모른다. 대신 두 문장을 못 박아 두어 **고침이 실렸는지**만
가린다. 옛 출력이 나오면 자료나 코드가 안 실린 것이다.
