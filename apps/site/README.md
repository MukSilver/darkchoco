# site — 다크초코 공개 사이트

세 산출물을 한 사이트에 두고 문만 나눕니다.

| 경로 | 산출물 | 누가 봅니까 |
|---|---|---|
| `/` | 세 갈래 문 | 처음 온 사람 |
| `/map` | 개인정보 유출 생태계 지도 | 기자 · 협업처 · 연구자 |
| `/guide` | 유출 대응 가이드라인 | 유출 피해자 · 일반 시민 |
| `/wiki` | 다크웹 RAG | 조사자 — **문 뒤에 둡니다** |

세 산출물이 같은 조사 자료를 쓰기 때문에 묶습니다. 지도에서 사건을 고르면 그 사건이
가이드로 그대로 넘어가고, 가이드에서 「이 사건이 어디를 거쳤나」를 누르면 지도의
그 경로가 밝아집니다. 사이트가 나뉘어 있으면 이 이음매가 끊깁니다.

---

## 서버가 없습니다

`data/leak-map.json` 하나를 읽어 그리는 정적 사이트입니다.
노션을 브라우저에서 직접 부르지 않습니다. **노션 토큰이 브라우저로 나가면 안 되기 때문입니다.**
크롤러 컨테이너에 노션 토큰을 넣지 않는 것과 같은 이유입니다.

```
노션  ──[tools/build_data.py · packages/dc_notion]──▶  data/leak-map.json  ──▶  브라우저
```

데이터를 갱신하려면 스크립트를 돌려 JSON 파일만 바꿉니다.

`/wiki`는 예외입니다. LLM을 불러야 해서 백엔드가 필요하고, 조사 자료가 그대로 들어가므로
공개하지 않습니다. 지금은 자리만 잡아 두었습니다.

---

## 폴더

```
apps/site/
  index.html          첫 화면 — 세 갈래 문
  map/index.html      생태계 지도
  guide/index.html    유출 대응 가이드라인
  wiki/index.html     RAG — 자리만
  assets/
    tokens.css        색 · 글자 · 간격. 세 구역이 같이 씁니다
    hex.js            육각 배치와 2층 투영. 지도의 뼈대
    shell.js          머리띠 · 이동 · 데이터 읽기
  data/
    schema.md         JSON 계약
    leak-map.json     실제 데이터 (지금은 예시)
  tools/
    build_data.py     노션 → JSON
```

---

## 띄우기

```bash
cd apps/site && python -m http.server 8080
```

`file://` 로 열면 `fetch`가 막혀 데이터를 못 읽습니다. 반드시 서버로 띄웁니다.

## 데이터 갱신

```bash
python apps/site/tools/build_data.py --out apps/site/data/leak-map.json
```

`NOTION_TOKEN_FILE` 이 있어야 합니다. 저장소에 토큰을 커밋하지 않습니다.

---

## 배포

저장소가 비공개이고 조사 코드가 같이 들어 있으므로 **저장소를 공개로 돌리지 않습니다.**
Vercel이나 Netlify에서 이 폴더만 가리켜 배포합니다. 둘 다 비공개 저장소에서 배포됩니다.

`/wiki`는 배포에 포함하지 않거나 인증 뒤에 둡니다.
